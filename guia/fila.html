Fila

O primeiro que entra é o primeiro que sai. Entra no fim (rear), sai da frente (front).

4 exemplos · enfileirar/desenfileirar O(1)

O que é

Uma fila é uma coleção linear com duas extremidades com papéis fixos: a frente (front) e o fim (rear). Elementos entram no fim e saem pela frente. Por isso a regra é FIFO — first in, first out: o primeiro que entra é o primeiro que sai.

A metáfora é a fila de espera: quem chegou primeiro é atendido primeiro; quem chega depois vai para o fim. A fila não oferece acesso ao meio — para chegar ao terceiro elemento, é preciso desenfileirar os dois primeiros.

Como funciona

  • enqueue(x) / enfileirar — coloca x no fim; o tamanho aumenta em 1.
  • dequeue() / desenfileirar — remove e devolve a frente; o tamanho diminui em 1.
  • front() / frente — devolve a frente sem remover.
  • isEmpty() / estaVazia e size() / tamanho — consultam o estado.

O invariante: a frente é o elemento mais antigo; o fim é o mais recente. Com um array, push no fim e shift na frente funcionam, mas shift custa O(n) porque desloca todos os vizinhos. Com os índices #inicio e #fim, a fila vira uma janela [#inicio, #fim): desenfileirar só avança o início, e o custo é O(1) amortizado.

const fila = ['A', 'B', 'C'];
console.log(fila.shift()); // A
console.log(fila[0]);      // B
fila.push('D');            // entra no fim
console.log(fila);         // [B, C, D]

Com uma lista encadeada, a frente é o início e o fim é o último nó: enfileirar e desenfileirar continuam O(1) se você mantiver as duas referências. A fila com índices é a versão de array que evita o shift.

Custo

Com n elementos na fila:

Custo das operações com n elementos
OperaçãoCustoObservação
enqueue(x)O(1)push no fim é amortizado; na lista, O(1) estrito.
dequeue() com índices/listaO(1)Avança o início ou religa o ponteiro; não desloca os vizinhos.
dequeue() com shiftO(n)O array desloca todos os elementos para a esquerda.
front()O(1)Só lê a frente, sem remover.
Busca por valorO(n)Percorre da frente ao fim; a fila não é feita para busca.
MemóriaO(n)Com índices, o array pode manter posições já consumidas até compactar.

A diferença entre O(1) e O(n) no dequeue aparece rápido: uma fila de 10 mil elementos com shift copia os outros 9.999 a cada saída.

Quando usar

Use quando a ordem de chegada é o critério:

  • Escalonamento: tarefas, impressões e requisições atendidas por ordem de chegada.
  • Buffers: producer/consumer, streams e filas de mensagens.
  • BFS: a busca em largura visita os nós na ordem em que eles entram na fila.
  • Simulações: clientes, pacotes e eventos processados em ordem temporal.

Quando evitar

  • Precisa do último que chegou? A estrutura é uma pilha.
  • Precisa do menor/maior elemento? Use um heap / fila de prioridade.
  • Precisa acessar o meio com frequência? Array ou lista são mais diretos.

Erros comuns

Antes de rodar
  • Usar pop em vez de shift: pop remove do fim e transforma a fila em pilha.
  • Usar shift em uma fila grande: a remoção no início é O(n); prefira os índices #inicio/#fim ou uma lista.
  • Confundir frente com fim ao ler o primeiro elemento: a frente é fila[0]; o fim é fila[fila.length - 1].
  • Chamar dequeue ou front sem verificar se a fila está vazia. No EDViz, a operação devolve undefined; em Java e C#, lança exceção.
  • Deixar a fila crescer sem limite: consumidores mais lentos que produtores enchem a memória.
  • Na fila com índices, achar que o array interno é a fila: a janela viva é [#inicio, #fim); o que está fora não conta.
