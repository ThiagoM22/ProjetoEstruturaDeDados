Array

Uma faixa contígua de posições, endereçada por índice. É a base de pilhas, filas e do array do próprio JavaScript.

1 exemplo · acesso O(1) · inserção no meio O(n)

O que é

Um array é uma sequência de posições acessadas por índice. No modelo didático, as posições ficam lado a lado na memória e o índice começa em 0: v[0] é a primeira, v[1] a segunda, e assim por diante. O acesso é direto — o programa calcula o endereço da posição e vai até ela, sem passar pelas anteriores.

O comprimento (length) é o tamanho da faixa; o tamanho lógico é quantas posições você está usando. O exemplo MeuArray mantém os dois separados (#items e #tamanho) justamente para mostrar a diferença. Em JavaScript o array cresce sozinho e pode ter buracos; o modelo de posições contíguas continua útil para entender o custo.

Como funciona

  • Ler e escrever por índice — v[i] = x é O(1): o endereço é calculado, não percorrido.
  • Adicionar no fim — push é O(1) amortizado; o array pode crescer e copiar os elementos de vez em quando.
  • Inserir ou remover no meio — é O(n): os vizinhos precisam deslizar para abrir ou fechar espaço.
  • delete v[i] — abre um buraco e não desloca ninguém; o comprimento continua o mesmo.
const v = [10, 20, 30];
console.log(v[1]);        // 20
v[1] = 25;                // escrita O(1)
v.splice(1, 0, 15);       // insere 15 no meio
console.log(v);           // [10, 15, 25, 30]

Custo

Com n posições no array:

OperaçãoCustoObservação
Acesso por índiceO(1)O endereço é calculado; não há caminhada até a posição.
Busca por valorO(n)Sem índice, é preciso varrer as posições.
Inserir/remover no fimO(1) amortizadoO array pode crescer e copiar os elementos de vez em quando.
Inserir/remover no início ou meioO(n)Os vizinhos deslizam para abrir ou fechar espaço.

MemóriaO(n)O array pode reservar capacidade extra para crescer.

O custo de inserir no meio é o que separa o array da lista encadeada: aqui, abrir espaço custa O(n); na lista, religar ponteiros custa O(1) depois de encontrar a posição.

Quando usar

Use quando o acesso por posição é a operação mais importante:

  • Leitura e varredura: percorrer todos os elementos, calcular médias, filtrar, mapear.
  • Acesso aleatório: pegar o elemento do meio, o último, o índice calculado.
  • Base de outras estruturas: pilha com push/pop e fila com push/shift (com a ressalva do custo).
  • Tabelas de apoio: contar frequências, mapear índices pequenos, buffers de tamanho conhecido.

Quando evitar

  • Inserir e remover no meio o tempo todo: a lista encadeada evita o deslocamento.
  • Fila grande com shift: cada remoção é O(n); use índices ou uma lista.
  • Dados esparsos com muitos buracos: o array guarda espaço vazio.
  • Precisa de ordem por prioridade: um heap resolve melhor.

Erros comuns

Antes de rodar
  • Confundir v[v.length] com v[v.length - 1]: o primeiro é a próxima posição livre; o segundo é o último elemento.
  • Confundir length com “quantidade de valores válidos”. O delete abre um buraco e o comprimento continua igual; use splice ou desloque à mão para remover de verdade.
  • Confundir splice com slice: splice altera o array; slice devolve uma cópia.
  • Usar shift em uma fila grande: a remoção no início desloca todos os vizinhos e custa O(n).
  • No MeuArray, esquecer de atualizar #tamanho depois de um deslocamento manual — o array interno e o tamanho lógico saem de sincronia.
